# 拾味小馆 · 智慧餐饮与商家评价管理系统

一套集 **在线订餐系统**、**商家主页与风采简介**、**多维食客评价与官方回复系统**、**商家数字化管理后台** 于一体的现代化全栈餐饮门户。

---

## 🌟 核心功能一览

### 1. 🍽️ 订餐系统 (Food Ordering)
- **多分类菜单展示**：支持招牌推荐、经典热炒、特色主食、滋补靓汤、精选凉菜、沁爽饮品等多级分类筛选，支持关键词实时检索。
- **高颜值菜品卡片**：展示高清食谱图片、月销量、推荐评分、划线原价、口感标签（如“招牌”、“微辣”、“外脆里嫩”）。
- **堂食 / 外卖双模点餐**：
  - **堂食点餐**：支持录入堂食桌号，实时免包装费核算；
  - **外卖打包**：自动核算外卖环保餐盒包装费，支持录入详细收件地址与联系方式。
- **快捷点单交互**：数量步进器增减、菜品大图详情弹窗、智能加购、清空购物车。
- **快捷订单备注**：一键添加常用备注标签（如“免葱”、“少辣”、“不放味精”、“尽快出餐”）。
- **订单追踪与流水**：生成唯一格式化订单号（如 `ORD-YYYYMMDD-XXXX`），完整展示“待接单 ➔ 制作中 ➔ 待取餐/配送 ➔ 已完成”的全生命周期状态流转与历史追溯。

### 2. 🏪 商家信息简介 (Merchant Profile & Story)
- **视觉形象展示**：全景实景头图、店铺 Logo、品牌 Slogan。
- **动态营业状态**：实时展示“营业中 (绿色脉冲呼吸灯)”或“已打烊/休息中”，支持商家一键切换。
- **关键经营指标**：营业时间（10:30 - 21:30）、订餐热线、高德/门店详细地址、人均消费（¥58/人）、累计销量与好评率。
- **广播公告栏**：顶部醒目喇叭轮播，发布当季新品、满减促销或节日公告。
- **品牌故事与匠心传承**：记录传承工艺与食材直采理念。
- **环境实景相册**：餐厅环境、明厨亮灶、用餐氛围相册实拍。
- **品质承诺与到店服务**：明厨亮灶、精选有机食材、免费WiFi、免费停车等特色标签。

### 3. ⭐ 食客评价与商家回复系统 (Reviews & Ratings)
- **多维度评分看板**：
  - 综合用户评分（如 4.8 / 5.0）；
  - 口味满意度百分比条形图与服务满意度评分；
  - 5星、4星、3星、2星、1星评分分布进度条。
- **精准筛选过滤器**：支持查看“全部评价”、“🌟 推荐好评 (4-5星)”、“💬 待改进反馈 (1-2星)”、“🏪 商家已答复”。
- **食客在线发表评价**：
  - 1-5 星交互式星级打分；
  - 口味分与服务分细分打分；
  - 就餐方式（堂食/外卖）；
  - 快捷印象标签多选（“食材新鲜”、“分量足”、“出餐快”、“镬气十足”）；
  - 推荐菜品多选（一键关联菜单招牌菜）；
  - 详细心得与建议文本录入。
- **商家官方回复 (Merchant Reply)**：商家在后台可针对每一条食客评价进行真诚、官方的回复，前台同步展示官方徽章、回复时间与答复正文。

### 4. ⚙️ 商家数字化管理工作台 (Merchant Admin Panel)
- **数据指标大屏**：今日营业额、今日完成订单数、待接单/制作中紧急订单提醒、综合好评率。
- **订单实时流转看板**：
  - 待接单 ➔ 【接单制作】 ➔ 【制作完成待取】 ➔ 【确认完成】；
  - 订单异常或退订一键取消。
- **菜品菜单管理**：
  - 录入新菜品（名称、分类、价格、原价、图片、标签、原料描述）；
  - 编辑菜品详情；
  - 一键上架 / 下架切换（实时同步给前台顾客）；
  - 菜品删除。
- **评价互动中心**：集中查看全店评价，筛选未答复评价，一键在线答复。
- **店铺资料维护**：在线修改店铺名称、Slogan、联系方式、营业时间、地址、公告广播、品牌故事等。

## 🏗️ 技术架构

- **后端开发**：Python 3.14 + **FastAPI**（高性能异步 Web 框架）+ **Uvicorn**（ASGI 服务器）
- **数据持久化**：**SQLite 3**（单文件关系型数据库，开箱即用，无需外部配置）
- **前端开发**：响应式宽屏桌面门户，基于 **Vue 3**（响应式数据双向绑定）+ **Tailwind CSS**（现代原子化设计系统）+ **FontAwesome 6** 图标库 + **SweetAlert2** 动效通知
- **零构建开箱即用**：前端采用浏览器现代 ES/CDN 原生无编译运行模式，无需安装 Node/Webpack/Vite，启动 Python 即可直接在浏览器畅快访问！

## 🚀 快速启动指南

### 方式一：双击一键启动 (推荐)
直接双击项目根目录下的 **`start.bat`** 脚本即可自动拉起服务。

### 方式二：命令行启动
```bash
# 1. 切换至项目根目录
cd d:\workspace\food_order_system

# 2. 启动 FastAPI 服务
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

启动完成后，打开浏览器访问：
- **前台系统与综合门户**：[http://127.0.0.1:8000](http://127.0.0.1:8000)
- **交互式 API 文档 (Swagger UI)**：[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- **Redoc API 文档**：[http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)
